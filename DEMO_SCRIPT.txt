Preparing for software engineering internships and placements can feel like navigating a maze in the dark. Students rarely get clear answers on where their skills fall short or whether they are actually prepared for technical interviews.

To solve this, I built Career Copilot. It is an adaptive, secure, local concierge agent that audits a student's resume against target job descriptions, designs a custom project-based learning plan, and coaches them through realistic, turn-based mock interviews.

[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let's look at the system architecture. (pause)
Everything is built on the Google Agent Development Kit 2.0 Workflow API. (pause)
When the student sends a message, it is first evaluated by our security checkpoint node, which scrubs PII like emails and phone numbers, checks for prompt injection keywords, and records structured audit logs. (pause)
Once cleared, the orchestrator node coordinates the conversation flow, routing requests based on user commands. (pause)
For skill gap analysis, the orchestrator calls our resume job match agent, which uses local MCP tools to read the candidate's resume and compares it against target requirements. (pause)
Next, the learning roadmap agent pulls these identified gaps, cross-references completed skills from the local progress store, and structures a prioritized roadmap containing resource recommendations and hands-on projects. (pause)
Finally, when the student wants to practice, the orchestrator triggers the run interview cycle node. This node coordinates with our interview coach agent to generate technical questions and utilizes a human-in-the-loop pause to wait for the student's response.

[3:00 — SECURITY & MCP]
(pause)
Under the hood, all file parsing and progress storage are handled through our local Model Context Protocol server. The server exposes stdio tools for read and write operations, meaning no raw student data ever leaves the local machine except for direct LLM analysis calls. Security is maintained by keeping all progress states strictly local and protected by the gateway checkpoint.
